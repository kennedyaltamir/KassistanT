# 01 — EXECUTION PROTOCOL

## Sequência operacional

1. Ler o Master Prompt.
2. Ler o estado atual.
3. Consultar GitHub real.
4. Conferir branch, SHA, remote e working tree.
5. Inspecionar o código existente.
6. Ler contratos e documentação relevantes.
7. Pesquisar referências externas quando necessário.
8. Definir a menor alteração segura.
9. Implementar.
10. Executar testes direcionados e a validação padrão.
11. Inspecionar diff.
12. Registrar evidências e decisões.
13. Publicar quando solicitado.
14. Conferir GitHub novamente.
15. Atualizar o estado da ROADMAP.

## Princípio

Nenhuma conclusão técnica importante deve depender somente de memória de conversa.
