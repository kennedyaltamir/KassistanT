# Domain Commands

Status: DEFINED / PARTIAL.

Order commands defined by baseline: CreateDraftOrder, AddItem, RemoveItem, ChangeQuantity, SetDeliveryType, SetAddress, SetPaymentMethod, ApplyEligiblePromotion, RecalculateOrder, RequestCustomerConfirmation, ConfirmOrder and CancelOrder.

Each command requires INPUT, PRECONDITIONS, BUSINESS RULES, OUTPUT, ERRORS, EVENTS and IDEMPOTENCY. Fully typed executable schemas remain PARTIAL.
